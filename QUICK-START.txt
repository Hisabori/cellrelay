CellRelay 0.11 빠른 시작
1. 아이폰 0.7 앱의 중계를 켜고 PC를 같은 핫스팟/로컬 네트워크에 연결합니다.
2. PC 연결 설정에서 QR 이미지, 클립보드 QR 또는 CR1 코드를 등록합니다.
3. 연결 방식을 선택하고 선택한 방식으로 연결을 누릅니다.
TCP: 브라우저 HTTP/HTTPS 프록시를 화면의 127.0.0.1 주소와 포트로 설정합니다.
TCP+UDP SOCKS5: 대상 앱의 SOCKS5 서버에 화면의 로컬 주소/포트를 입력합니다. UDP는 해당 앱이 UDP ASSOCIATE를 지원해야 합니다. 관리자/터널 엔진은 필요 없습니다.
UDP: 목적지 서버/UDP 포트와 PC 로컬 포트를 입력합니다. 앱이 로컬 UDP 포트로 전송하도록 설정합니다.
VPN: PC 전체 TCP·UDP·DNS 경로를 아이폰으로 보냅니다. 엔진 준비와 관리자 권한이 필요하며 GAME-MODE.txt를 참조하세요. 외부 VPN 프로필은 지원하지 않습니다.
4. 사용 후 상단 모든 연결 중지를 누릅니다. 브라우저/앱에서 직접 지정한 프록시는 원래대로 복구하세요.
수신 중/엔진 실행 중 표시는 인터넷 성공을 뜻하지 않습니다. 실제 기기·게임·VPN 복원과 통신사 공유 데이터 집계는 미검증입니다. 무기한 아이폰 백그라운드는 지원하지 않습니다.


UDP 검사: SOCKS5 탭의 아이폰 UDP·DNS 검사로 현재 중계 경로를 검사합니다. VPN 시작은 HTTPS → UDP·DNS → 엔진 설정 → 엔진 시작 순서입니다. UDP 검사는 8초 안에 완료되어야 하며 취소할 수 있습니다. 1.1.1.1:53 검사 서버가 차단되면 VPN 화면에서 시작 전 검사를 해제할 수 있습니다. 검사 성공은 모든 앱/게임의 성공을 의미하지 않습니다.


백그라운드: PC 창 닫기는 기본적으로 트레이로 숨깁니다. 완전 종료는 트레이 오른쪽 메뉴에서 선택하세요. 아이폰은 화면을 켜 둔 테스트가 기본이며 백그라운드는 iOS 허용 시간 안에서 기존 연결만 마무리합니다. 새 아이폰 0.8은 자동 재개 설정을 저장합니다.
