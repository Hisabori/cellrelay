CellRelay 0.8 게임 모드 (실험 기능)

준비
1. PC ZIP 전체를 새 폴더에 압축 해제하고 기존 CellRelay 창을 종료합니다.
2. 아래 공식 릴리스에서 sing-box-1.14.3-windows-amd64.zip을 내려받습니다. 터널 엔진은 별도 외부 프로그램이며 이 ZIP에 포함하지 않습니다.
https://github.com/SagerNet/sing-box/releases/tag/v1.14.3
공식 엔진 ZIP SHA256: d8b86ef58936dba9230ec6a57ffa4243933f3c14ef4809828b6c553440ed1518
3. 엔진 ZIP의 sing-box.exe, libcronet.dll, LICENSE를 CellRelay의 Desktop/Engine 폴더 안에 넣습니다.
4. Desktop/CellRelay.exe를 마우스 오른쪽 버튼으로 누르고 관리자 권한으로 실행합니다.

연결
1. 아이폰 0.7 앱에서 중계를 시작하고 PC를 같은 핫스팟에 연결합니다. 아이폰 화면을 켜 둡니다.
2. PC에서 QR 이미지/클립보드 QR/CR1 코드로 연결 정보를 등록합니다.
3. 게임 모드 · 지포스 나우 탭에서 게임 모드 시작을 누릅니다. 다른 VPN과 기존 브라우저 프록시는 종료/해제한 상태로 테스트하세요.
4. 터널 엔진 실행 중 표시 후 지포스 나우를 열어 네트워크 검사와 게임 접속을 확인합니다. 이 표시는 게임 접속 성공을 의미하지 않습니다.
5. 사용 후 게임 모드 중지를 누릅니다. 이 앱이 시작한 엔진만 종료합니다. 실제 장치에서 경로 복원은 아직 확인하지 않았습니다.

범위
이 모드는 PC 전체 TCP·UDP와 DNS 경로를 아이폰 중계로 바꿉니다. ICMP 및 외부에서 먼저 시작하는 연결은 지원하지 않습니다. 기존 HTTP 프록시와 고정 UDP 전달은 별도 탭에서 계속 사용할 수 있습니다.
UDP는 PC-아이폰 사이에서 TCP 터널로 전달되므로 재전송 대기와 지연이 증가할 수 있습니다. 실제 TUN 시작/종료, 게임 접속·화질·지연 및 통신사 데이터 집계는 미검증입니다. 아이폰 앱의 무기한 백그라운드는 지원하지 않습니다.

검증
Windows 빌드 및 로컬 회귀검사 통과: TCP 반닫힘/왕복, 동적 UDP 목적지, SOCKS UDP 단편 거절, 연결 종료 처리, QR 등록, 기존 프록시 회귀검사.
공식 sing-box 1.14.3으로 생성한 터널 설정 검사가 통과했습니다. PC의 실제 네트워크 경로는 개발 중 변경하지 않았습니다.
